# 考勤系统（武汉一中管理平台）云服务器部署指南

> 目标：把本地运行的考勤系统部署到云服务器，让任何人通过 `http://服务器公网IP` 直接访问。
> 全程约 30-60 分钟，不需要域名。

---

## 第 1 步：购买云服务器（约 10 分钟）

**推荐配置（校园规模够用）：**

| 项目 | 建议 |
|---|---|
| 产品 | 腾讯云 **轻量应用服务器** 或 阿里云 **ECS/轻量应用服务器** |
| 规格 | 2核2G 内存、50GB 系统盘（约 ¥50-112/月，新用户首年常有优惠） |
| 操作系统 | **Ubuntu 22.04 或 24.04**（务必选这个，脚本按此编写） |
| 地域 | 离学校近的地域（如成都、北京、上海等） |
| 带宽 | 3-5 Mbps 起步，纯文字+轻图表足够 |

购买地址：腾讯云 `cloud.tencent.com` / 阿里云 `aliyun.com`，搜「轻量应用服务器」。

**买完后必做的两件事：**

1. 在控制台「重置密码」，设置 root 登录密码。
2. 在「防火墙 / 安全组」中**只放行两个端口**：
   - `22`（SSH，一般默认已开）
   - `80`（HTTP 网页访问）
   - ⚠️ **不要放行 5432**（PostgreSQL 数据库端口绝不能暴露公网）

---

## 第 2 步：在本地打包并上传代码（约 10 分钟）

在你这台 Windows 电脑的 PowerShell 中执行：

```powershell
# 1. 打包（自动排除 node_modules 和缓存，包很小）
tar -czf "$env:USERPROFILE\Desktop\attendance.tar.gz" --exclude=node_modules --exclude=.npm-cache --exclude=.git -C "E:\AI教育应用" AttendanceSystem

# 2. 上传（把 <IP> 换成服务器公网 IP）
scp "$env:USERPROFILE\Desktop\attendance.tar.gz" root@<IP>:/root/
```

然后在服务器上解压（SSH 登录服务器后执行）：

```bash
ssh root@<IP>                    # 本地执行，登录服务器
mkdir -p /opt
tar -xzf /root/attendance.tar.gz -C /opt
mv /opt/AttendanceSystem /opt/attendance
```

---

## 第 3 步：一键部署（约 5 分钟）

在服务器上执行：

```bash
sudo bash /opt/attendance/deploy/deploy.sh
```

脚本会自动完成：安装 Node.js 20 / PostgreSQL / Nginx / PM2 → 创建数据库（随机密码）→ 生成 `.env` → 启动应用 → 配置开机自启 → 配置 Nginx。

结束时屏幕上会显示**访问地址和数据库密码**，请截图保存。

---

## 第 4 步：验证访问

在浏览器打开：`http://服务器公网IP/login`，用默认账号 `admin / 123456` 登录。

**⚠️ 登录后第一件事：进入个人中心修改 admin 密码**（默认密码裸奔在公网上非常危险）。

---

## 第 5 步：把本地旧数据导入云服务器（如需保留现有数据）

**① 在本地 Windows 导出数据库**（PowerShell，按你的 PostgreSQL 安装版本调整路径）：

```powershell
& "C:\Program Files\PostgreSQL\16\bin\pg_dump.exe" -U postgres -d testdb -F c -f "$env:USERPROFILE\Desktop\attendance_backup.dump"
```

**② 上传到服务器：**

```powershell
scp "$env:USERPROFILE\Desktop\attendance_backup.dump" root@<IP>:/root/
```

**③ 在服务器上恢复**（数据会覆盖进部署时创建的 attendance 库）：

```bash
sudo -u postgres pg_restore -d attendance --no-owner --role=attendance /root/attendance_backup.dump
sudo systemctl restart nginx   # 不必须，但顺手刷新
pm2 restart attendance
```

刷新浏览器即可看到原有班级、学生、考勤数据。

## 日常维护速查

| 操作 | 命令（在服务器上执行） |
|---|---|
| 查看运行状态 | `pm2 status` |
| 查看日志 | `pm2 logs attendance` |
| 重启应用 | `pm2 restart attendance` |
| 更新代码后重启 | 替换代码 → `cd /opt/attendance/server && npm install --omit=dev` → `pm2 restart attendance` |
| 备份数据库 | `sudo -u postgres pg_dump -F c attendance > /root/backup_$(date +%F).dump` |

> 提示：应用重启后所有登录会话会失效（用户需重新登录），属正常现象。

---

## 常见问题

- **打不开页面（超时）**：检查云控制台安全组是否放行了 80 端口（第 1 步第 2 件事）。
- **页面显示 502**：应用没起来，执行 `pm2 logs attendance` 看报错；常见原因是数据库未导入、`.env` 密码不对。
- **登录后提示数据库错误**：确认已执行第 5 步数据导入，且 `.env` 中 DB_PASSWORD 与部署时输出的一致。
- **想上传大附件报 413**：修改 `/etc/nginx/sites-available/attendance` 中的 `client_max_body_size`，然后 `systemctl reload nginx`。

---

## 后续升级路线（可选）

1. **绑定域名**：购买域名 → 域名 ICP 备案（大陆服务器必须）→ 修改 Nginx `server_name`。
2. **HTTPS**：备案后用 certbot 免费签发证书，`apt install certbot python3-certbot-nginx && certbot --nginx`。
3. **定期备份**：加一条 crontab 每天自动 `pg_dump` 到 `/root/backups/`。
